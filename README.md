# KRATOS-Voice-Assistant
🤖 KRATOS is an AI-powered voice assistant built in Python that enables real-time speech interaction, system-level automation, and intelligent responses using modern AI models.It is designed to work with instant listening (no wake word) and supports both offline commands and online AI capabilities.

✨ Features

i.🎙️ Real-time Speech Recognition (instant listening, no wake word)

ii. 🧠 AI-Powered Responses using modern language models

iii. 🖥️ System Automation

        1. Open applications

        2. Control devices Shutdown / Restart / Lock system

        3. Type text automatically

        4. Create files

iv. 🔌 Offline Command Handling (works even if AI is unavailable)

v.  🧩 Modular & Extensible Architecture

vi. ⚡ Lightweight and fast execution

🛠️ Tech Stack

    1. Programming Language: Python

    2. Speech Recognition: SpeechRecognition

    3. Audio Processing: sounddevice, soundfile

    4. Text-to-Speech: pyttsx3

    5. System Automation: pyautogui, os

    6. AI Integration: OpenAI API
